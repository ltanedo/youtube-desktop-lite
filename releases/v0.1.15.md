## YouTube Desktop Pake v0.1.15

Adds integrated Windows ad blocking using Brave's **adblock-rust 0.13.3**:

- Native WebView2 request filtering, early YouTube scriptlets and cosmetic filters, enabled by default.
- **Shield** button or **Ctrl+Alt+B** opens the persistent on/off toggle, diagnostic counters and filter updates.
- Bundled filters work offline at startup. Validated updates are cached atomically and apply after restarting; invalid updates retain the previous filters.
- Settings panel works with YouTube's Trusted Types security policy.
- Preserves the existing login profile, startup-paint fix, zoom reflow, fullscreen controls/captions, fade transitions and persistent **D** ultrawide toggle.

### Downloads

- **YouTube.exe** — standalone Windows x64 executable; no installer required.
- **YouTube.msi** — Windows x64 installer.

Both use the existing YouTube app profile. Microsoft Edge WebView2 Runtime is required.

### Verification and limitations

These are the exact locally tested artifacts, not a new rebuild. The release build, four Rust tests and enabled/disabled browser fixtures passed, including early script execution and the Trusted Types regression. The app launched with the existing signed-in session and Shield control present.

Live pre-roll/mid-roll blocking is not guaranteed; this is not full Brave Shields or uBlock Origin parity. Use Shield to disable blocking if playback has problems. Real playback, ads when served and fullscreen behavior remain subject to user testing. See [coverage and build instructions](https://github.com/ltanedo/youtube-desktop-lite/blob/v0.1.15/native/README.md) and the [test record](https://github.com/ltanedo/youtube-desktop-lite/blob/v0.1.15/native/TEST-RESULTS.md).
