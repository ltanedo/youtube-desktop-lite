## YouTube Desktop Pake v0.1.16

Fixes a filtering gap that allowed some end-of-video ads through after startup ads were blocked.

- Removes ad-only fields from later player, next-video and watch responses, including fetch and XHR requests with or without query strings.
- Applies the fix to both bundled and cached filter sets; no login/profile reset is required.
- Keeps video streams, captions, recommendations and end screens intact. No fast-forwarding or Skip-button automation.
- Preserves the existing fullscreen fades, controls, D-key ultrawide setting and startup-paint fix.

### Verification

The user confirmed post-roll ads no longer appeared in their test. Four Rust tests and 192 late-response browser cases passed, along with the existing startup-scriptlet and settings-panel tests. This does not guarantee blocking every future YouTube ad variant.

These are the exact tested Windows x64 artifacts, without a rebuild:

- **YouTube.exe** — standalone executable.
- **YouTube.msi** — Windows installer.

Use **Shield** or **Ctrl+Alt+B** for the blocking toggle and diagnostics. The filter version includes `+pake-late-ads-1`.
